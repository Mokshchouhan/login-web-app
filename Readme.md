# Flask Login Web App

## Features
- User Registration
- User Login
- Animated Success Screen
- Modern UI (Glassmorphism)

## Tech Stack
- Python (Flask)
- HTML, CSS, JS

## Run Locally
pip install flask
python app.py

login-web-app/
├── app.py # Main Flask application
├── users.txt # User data storage
├── .gitignore # Files to ignore in Git
├── README.md # Project documentation
├── static/
│ └── style.css # CSS for styling pages
└── templates/
